Bitcoin Cash governance

How BCH consensus works

Bitcoin Cash upgrade discussions and proposals are public. A hard fork changes the rules that compatible nodes and miners follow.

  1. Community members discuss ideas in public forums such as BitcoinCashResearch.org and consensus.cash.
  2. Proposed protocol changes can be documented through the Cash Improvement Proposals (CHIPs) process.
  3. Developers review and implement proposals in node software; miners, businesses, exchanges, and users decide which software to run.
  4. At an activation point, nodes validate blocks according to the rules in their software. Incompatible rules can cause a chain split.
  5. Participants and services determine which chains they continue to support; no single organization or formal network-wide vote decides for everyone.

Key point: Discussion and CHIP documentation help coordinate upgrades, but do not themselves activate a change. Network outcomes depend on participants adopting compatible rules and continuing to use them.
